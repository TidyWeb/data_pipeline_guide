# The Data Pipeline — A Field Guide

An illustrated guide to the data pipeline for people learning Python for data
analysis: how a fact about the world becomes a row, how a row becomes a shape,
and how a shape becomes a picture.

**Read it here:** https://tidyweb.github.io/data_pipeline_guide/

## What it covers

- The five stages: collection, storage, shaping, analysis, visualisation
- Data quality vs. richness, and why aggregation is a one-way street
- Where SQL sits, and why a pandas-only course is still a complete pipeline
- What "shape" means, drawn out from scalar to three dimensions
- Why NumPy trades flexibility for speed, and where the compiled C comes from
- How the stack fits together: C, NumPy, pandas, charting
- Three ways a picture can mislead: Anscombe's Quartet, Simpson's paradox
  (kidney stones and Berkeley), and chart-craft failures including the
  Challenger O-ring presentation

## Files

- `index.html` — the guide, self-contained apart from the logo
- `assets/tidyweb_logo.png` — branding

No build step, no dependencies. Open `index.html` in any browser.

## A note on the diagrams

Several figures are schematic — drawn to show the structure of an argument
rather than to plot the exact source data. The Anscombe panels, the Berkeley
department figures and the Challenger scatter should not be quoted as the
underlying datasets.
